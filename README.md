# Python File Organizer

A simple Python automation tool that organizes files into folders based on file type.

## Features

- Automatically sorts files
- Creates folders if needed
- Supports Images, Documents, Videos, Audio and Archives
- Generates a log file
- Handles duplicate filenames

## Technologies Used

- Python
- os module
- shutil module

## Example

Before:

photo.jpg
resume.pdf
song.mp3

After:

Images/photo.jpg
Documents/resume.pdf
Audio/song.mp3
